# Old Python-Based ACR Content

This directory contains the previous Atomic Config Replace (ACR) content that was originally in the MkDocs lab guide at `docs/day-1/atomic-operations.md`.

## What's Here

- **python-acr-demos.md** - Original lab content covering Python-based ACR workflows with demos for syntax error detection and automatic rollback

## Why Was This Moved?

The lab guide has been updated to use the new **Ansible-based ACR framework** which provides:
- More structured, repeatable workflows
- Better integration with CI/CD pipelines
- Safer preview and dry-run capabilities
- Support for both CLI-RPC and YANG/XML workflows

## Reference

The original Python-based scripts can still be found in this repository at:
- https://github.com/jeremycohoe/cisco-ios-xe-atomic-config-replace

The new Ansible framework is documented at:
- https://github.com/jeremycohoe/iosxe-atomic-netconf-ansible
